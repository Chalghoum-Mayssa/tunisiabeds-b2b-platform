##  Project Description

This project titled **"Development of a Modular B2B Platform for Centralized Hotel Booking Management"** was carried out at **WorldSoft** as part of a Final Year Project (PFE) for the **Bachelor’s degree in Software Engineering (GLSI), Faculty of Sciences of Tunis (2024–2025)**.

WorldSoft is a company specialized in tourism platforms that connect multiple hotel suppliers through unified APIs to simplify booking processes for travel agencies.

The main objective of this project is to integrate a new hotel supplier, **TunisiaBeds**, into the existing multi-provider ecosystem by developing a **B2B interface** that allows travel agencies to search, view, and book hotel rooms through a centralized platform.

In addition, an **Artificial Intelligence module for anomaly detection** has been implemented to monitor system behavior and enhance security.

---

##  Objectives

- Develop a microservice to consume TunisiaBeds APIs.
- Standardize data between the supplier format and the central system.
- Ensure communication with existing modules (users, commissions, booking system).
- Integrate TunisiaBeds services into the B2B web platform for travel agencies.
- Design and implement an AI-based anomaly detection system to:
  - Detect abnormal business behavior automatically
  - Enable real-time monitoring
  - Block suspicious or malicious user accounts
  - Improve accuracy and reduce manual supervision
